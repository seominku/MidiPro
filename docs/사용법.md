# MidiPro 사용법 (1.1)

MIDI 시퀀서 + 오디오 녹음 + VST3 호스트. 이 문서는 전체 기능을 작업 흐름 순서로 정리한 것입니다. 새 기능 이력은 `CHANGELOG.md` 참고.
프로그램 안에서 **F1**을 누르면 단축키 요약 창이 열립니다.

---

## 1. 시작하기

- 실행: `MidiPro.exe`
- 설정·자동 저장·창 배치는 `%LOCALAPPDATA%\MidiPro`에 저장됩니다.
- **파일 > 새 곡 (템플릿)...** — BPM, 트랙 수, 박자를 정하고 한 번에 시작.
- **파일 > 최근 프로젝트** — 최근 연 .midipro 8개를 클릭 한 번으로 열기.
- 3분마다 자동 저장되고, 비정상 종료 시 다음 실행에서 복구를 물어봅니다.

## 2. 창 구성 (Tool 메뉴에서 켜고 끔)

| 창 | 역할 |
|---|---|
| 트랜스포트 | 재생/녹음/템포/루프/메트로놈/카운트인/버전 분기 |
| 트랙 뷰 | 트랙 레인(클립·노트 미리보기) + 헤더(볼륨/미터/FX) |
| 피아노 롤 | 노트 편집 + 벨로시티/CC/피치 벤드 레인 |
| 드럼 트랙 | 피아노 롤식 타임라인에 드럼 찍기 (위=크래시, 아래=킥) |
| 믹서 | 마스터 + 모든 트랙 스트립 (가로 스크롤, 마스터 고정) |
| 채널 | 마스터 + 선택 트랙만 (왼쪽 컴팩트 창) |
| 트랙 | 간단 트랙 목록 (뮤트/채널/미니 미터) |
| 성능 | FPS/CPU/오디오 콜백 부하/버퍼/보이스 |

창 위치/크기/도킹은 자동으로 저장됩니다.

## 3. 소리 설정

- **설정 > 개인설정 > ASIO** — 오디오 인터페이스 장치 검색/선택, 버퍼(자동 권장).
- 출력 기본값은 내장 신디사이저입니다. 트랙에 VST 악기를 얹으면 그쪽으로 연주됩니다.
- **설정 > 개인설정 > MIDI 장치 / 신디사이저 / 테마** 탭도 함께 확인하세요.
- **테마**: 프리셋 4종 + 강조색/배경/글자/둥글기 커스텀 + 고급 색 편집기. 자동 저장.

## 4. 트랙과 녹음

트랙 뷰 헤더(왼쪽 칸) 구성: 번호(드래그=순서 변경) · M(뮤트) · 이름 / ●녹음 · ASIO · 입력 선택 / FX 박스 / 세로 볼륨 · 레벨 미터.

- **MIDI 녹음**: 트랙 선택 후 `R` 또는 ●녹음. 카운트인을 켜면 정한 횟수만큼 클릭 후 시작.
- **오디오 녹음**: ASIO 버튼으로 저지연 모니터를 켜고 ●녹음. 루프 중이면 한 바퀴에서 자동 펀치아웃.
- **건반 연주**(트랜스포트): 컴퓨터 키보드로 연주/녹음. `Z X C V B N M`=도~시, `S D G H J`=검은건반, `,`=한 옥타브 위 도, `[ ]`=옥타브 이동.
- **FX 박스의 [+]** — 악기(VSTi) / FX(이펙트) / **내장 이펙트** / 프리즈 선택. 항목 더블클릭=편집기(내장은 파라미터 창), 우클릭=제거.
- **내장 이펙트**: VST 없이 쓰는 기본 5종 — **EQ**(3밴드), **딜레이**, **리버브**, **컴프레서**(스레숄드/비율/어택/릴리스/메이크업, GR 표시), **리미터**. VST와 같은 체인에 섞여 순서대로 걸리고, 파라미터는 프로젝트에 저장됩니다. 슬라이더 더블클릭=기본값.
- **기본 EQ**: 새 트랙에는 EQ가 자동으로 달립니다. 믹서/채널 창의 **저·중·고 미니 페이더**로 바로 조절 (더블클릭=0dB). 지우면 + EQ 버튼으로 다시 추가.
- **프리즈**: 무거운 VSTi 트랙의 MIDI를 오디오로 구워 CPU를 아낍니다 (FX는 계속 적용, 해제 시 MIDI 복귀).

## 5. 오디오 클립 편집 (트랙 뷰)

- 임포트: "오디오 임포트" 버튼 또는 탐색기에서 드래그&드롭 (MP3/WAV/FLAC).
- **클릭** = 선택(흰 테두리) · **드래그** = 이동 (다른 레인에 놓으면 트랙 이동)
- **끝 드래그** = 트림 · **Shift+끝 드래그** = 배속(음정 변함) · **Ctrl+끝 드래그** = 음정 유지 스트레치
- **Ctrl+몸통 드래그** = 구간 선택 → `Ctrl+C` 그 부분만 복사 / `Del` 구간 삭제(공백) / `Shift+Del` 잘라내고 당겨 붙이기 (클립이 없는 빈 곳에서도 Ctrl+드래그로 구간을 잡아 `L`로 루프 지정 가능)
- **Shift+클릭** = 다중 선택 → `Ctrl+M` 또는 우클릭으로 병합
- **Ctrl+C/V** 복사/붙여넣기 · **Ctrl+D** 복제(바로 뒤에)
- 선택 클립의 **위 모서리 흰 점** = 페이드 인/아웃 핸들
- 우클릭 메뉴: 자르기(가위) · 복사 · 리버스(역재생) · 병합 · 삭제 · 페이드 · 게인 · 정규화(-1dB)

### MIDI 클립 (어레인지 블록)

- 트랙 뷰 우클릭 → **"이 마디를 MIDI 클립으로"** (또는 빈 곳 Ctrl+드래그로 구간을 잡고 → "선택 구간을 MIDI 클립으로") — 노트들이 파란 블록으로 묶입니다.
- **클립 드래그** (몸통 아무 데나) = 이동 — 안의 노트/CC가 박 단위 스냅으로 함께 움직입니다. **클릭**(안 끌면) = 재생 위치 이동, **우클릭** = 이름 바꾸기 / **복제(바로 뒤에)** / 클립 해제(노트 유지) / 노트와 함께 삭제. Ctrl+드래그 구간 선택은 클립 위에서도 됩니다.
- **소유 개념**: 클립은 만들 때 범위 안에 있던 노트를 "소유"하고, 이동/복제/삭제는 소유 노트만 대상입니다 — 남의 노트 위에 놓아도 흡수하지 않습니다. **클립 범위 안에 새로 그리거나 옮겨 넣은 노트는 자동으로 소유**되고 (녹음·퀀타이즈·스윙·휴머나이즈 포함), 지우면 자동 탈퇴합니다. 필요하면 우클릭 → "범위 안 노트 다시 담기"로 한 번에 갱신할 수도 있습니다.
- 클립은 "구간 라벨"이라 피아노 롤 편집은 평소처럼 자유롭고, 프로젝트에 함께 저장됩니다.

## 6. 피아노 롤

- **클릭(빈 칸)** = 노트 추가, **그대로 드래그** = 경로에 연달아 생성(페인트)
- **노트 드래그** = 이동(소리 미리듣기) · **노트 끝 드래그** = 길이 조절(↔ 커서)
- `1~4` = 노트 길이(4/8/16/32분) · **Ctrl+클릭** = 길이 반 · **우클릭** = 삭제
- **Shift+드래그** = 범위 선택 → 이동/`Ctrl+C/V`/`Ctrl+D`/`Del`
- **퀀타이즈**(`Q`) = 격자에 스냅 · **휴머나이즈** = 타이밍/세기를 살짝 흔들어 사람 느낌
- **스케일** 콤보 = 조성 구성음 줄을 초록으로 표시 · **고스트** = 다른 트랙 노트 흐리게 표시
- 아래 레인 콤보: **벨로시티** / **CC 곡선**(모듈레이션·익스프레션·서스테인·팬 — VST 악기에 적용) / **피치 벤드**(가운데=0, 초록 곡선)
- **벨로시티 도구**: 벨로시티 레인 **우클릭** → 램프(크레센도/디크레센도), 랜덤 ±, 일괄 설정 — 선택 노트(없으면 전체)에 적용
- **기타 트랙 + 타브 악보**: **+ 트랙 추가 → 기타 트랙**으로 만들면 타브(TAB) 창이 열립니다 — 피아노 롤에서 노트를 입력하면 6줄 타브(표준 튜닝 EADGBE)에 프렛 번호가 자동 표시됩니다 (프렛이 가장 작은 줄로 배정, 음역 밖은 빨간 ?). **가져온 악보의 노트는 악보가 지정한 줄(운지) 그대로** 표시됩니다. 클릭=재생 위치, 휠=확대, Ctrl+휠=가로 스크롤. 기타 트랙 레인을 클릭하면 창이 자동으로 뜹니다. **[표시 트랙]** 버튼으로 여러 트랙을 골라 악보의 단처럼 **위아래로 나란히** 볼 수 있습니다 (기타 1·2 비교용 — PDF에서 파트 2개를 가져오면 자동으로 둘 다 표시). 트랙 뷰나 채널 창에서 트랙을 **Shift+클릭**해도 타브 창에 추가/제거됩니다 — 클릭한 순서가 보표 순서가 됩니다.
- **연습 모드 (리듬 게임)**: 타브 창의 **[연습]** 버튼 — 기타를 오디오 입력(ASIO 모니터 또는 녹음 입력)에 연결하고 재생과 함께 따라 치면, 음정과 박자를 판정합니다. 버튼 옆 콤보로 **어느 트랙을 기준으로 판정할지** 고를 수 있고(기본 = 첫 표시 트랙), 대상 보표에는 "◀ 연습 중" 표시가 붙습니다.
  - 판정: <span style="color:green">**GREAT**</span>(±60ms) / <span style="color:orange">**GOOD**</span>(±140ms) / <span style="color:red">**BAD**</span>(음정 틀림·박자 초과·놓침). 버튼 옆에 **정확도 %** 와 마지막 판정이 색으로 표시됩니다.
  - 맨 아래 **연주** 줄은 6줄 미니 타브입니다 — 내가 친 음이 악보와 같은 줄 위치에 프렛 번호로 찍히고, **코드는 구성음마다** 울린 줄은 판정 색(주황/초록), 안 울린 줄은 빨강으로 표시됩니다. 어느 줄이 빠졌는지 바로 보입니다.
  - **코드도 정확히 판정합니다**: 스트로크 소리에서 코드 구성음 하나하나가 실제로 울리는지 스펙트럼으로 확인합니다 (절반 이상 맞으면 인정, GREAT까지 가능). 기타 튜닝이 ±30센트쯤 나가 있어도 잡아냅니다. 코드 판정은 소리가 쌓일 시간이 필요해 표시가 0.15초쯤 늦게 뜹니다. **판정 전에 튜닝부터 맞춰주세요** — 반음 가까이 나가면 다른 음으로 판정됩니다.
  - **줄 구분은 못 합니다**: 2번줄 9프렛과 1번줄 4프렛은 같은 음이라 소리만으로는 어느 줄인지 알 수 없습니다 (음정 기준 판정). 판정된 음은 악보가 지정한 줄 위치에 표시됩니다.
  - **이펙트**: 앱 안에서 건 이펙트(모니터 FX)는 판정에 영향이 없습니다 — 판정은 이펙트 앞의 드라이 신호로 합니다. 외부 페달/앰프를 거친 입력은 판정 정확도가 떨어질 수 있으니, 기타를 인터페이스에 직결하고 이펙트는 앱에서 거는 걸 권합니다.
  - **판정 방식**: 악보 주도 청취 — 각 악보 음마다 그 시각 주변에서 "그 음이 실제로 새로 울리기 시작했는가"를 배음 에너지로 직접 확인합니다. 악보에 없는 여분의 스트럼은 무시되므로 헛 x가 뜨지 않고, 표시는 악보 음 위치에 줄별 색(초록 GREAT/주황 GOOD/빨강 놓침·틀림)으로 나타납니다. 판정 표시는 소리보다 약 0.3~0.6초 늦게 붙습니다(확인 창이 필요해서 정상입니다).
  - **자동 맞춤(권장)**: 오프셋 슬라이더 옆 **자동 맞춤** 버튼을 누르면 전용 창이 열립니다. 창의 미니 악보가 "무엇을 칠지"(3번줄 개방현 G × 16박)를 보여주고, **측정 시작**을 누르면 킥 4번 카운트인 후 100BPM 클릭이 16번 울립니다. 클릭마다 한 번씩 치면 박마다 감지 여부가 초록/빨강으로 표시되고, 끝나면 오프셋(시간차 중앙값)과 감도(검출 여유 배율)가 자동 설정됩니다. 12번 이상 감지돼야 하며, 결과는 슬라이더에 반영되므로 이후 직접 미세조정할 수 있습니다.
  - **지연 보정(자동)**: 입력 장치 지연은 자동으로 학습됩니다 — 박에 맞춰 몇 번(4번 이상) 치면 타격들의 시간차 중앙값을 재서 저절로 맞춰집니다. 처음 몇 번은 판정이 어긋날 수 있고, 보정이 잡히면 툴바에 `자동 +N ms`가 표시됩니다. **Δ 표시**는 최근 타격과 가장 가까운 악보 음의 시간차(+는 늦음)이고, 자동 보정 후에도 어긋나면 **오프셋 슬라이더**로 미세조정할 수 있습니다.
  - **마이크 사용 시**: 스피커로 곡을 틀면 마이크가 곡 소리를 타격으로 잘못 감지합니다. 마이크로 연습할 때는 **헤드폰**을 쓰세요.
  - 되감거나 루프하면 그 구간을 다시 판정할 수 있습니다.
- **타브 가져오기**: 타브 창 툴바의 **[타브 가져오기]** — 두 가지 방법이 있습니다.
  - **[PDF 열기]**: 악보 사이트에서 받은 **PDF 악보**를 그대로 엽니다. 6줄 타브 보표를 찾아 프렛 숫자를 읽고, **음표(기둥·빔·부점)까지 읽어 리듬을 그대로 재현합니다** — 8분·16분·부점·슬래시(같은 코드 다시 치기)가 박자에 맞게 들어갑니다. 마디선을 기준으로 매 마디 시각을 다시 맞추기 때문에 오차가 뒤로 번지지 않습니다. 한 단에 기타 1·2처럼 타브가 여럿이면 **파트마다 트랙을 따로 만들어** 나눠 넣고, 트랙 이름이 **"곡명 · 기타 1/2"** 로 묶입니다. 이 트랙들엔 어느 악보의 몇 번 파트인지 꼬리표가 붙어(프로젝트에 저장) **같은 악보를 다시 가져오면 새 트랙을 만들지 않고 그 트랙을 지우고 덮어씁니다** — 앱을 껐다 켜도 그대로입니다. (DRM/암호가 걸린 PDF도 대부분 열립니다.)
  - **도돌이표(‖: … :‖)를 펼쳐서 넣습니다** — 반복 구간을 두 번 연주하도록 자동으로 늘려 줍니다 (상태줄에 "도돌이표 N곳 펼침"으로 표시). 시작 기호가 없는 도돌이표는 곡 처음부터 되돌아갑니다. **1번·2번 괄호(볼타)와 D.C./D.S./Coda는 아직 지원하지 않습니다** — 그런 악보는 가져온 뒤 어레인지 뷰로 다듬어 주세요.
  - **텍스트 타브 붙여넣기**: Ultimate Guitar 같은 곳의 **ASCII 타브**를 그대로 붙여넣기 (Ctrl+V). 여러 단은 시간상 이어 붙고, `12` 같은 두 자리 프렛도 인식합니다.
  - 리듬 표기가 없는 타브(텍스트 타브 등)는 리듬 정보가 없어서 **한 칸 = 8분/16분/32분**을 골라 넣습니다. 노트는 **재생 위치의 마디 시작부터** 들어가고 Ctrl+Z로 되돌릴 수 있습니다.
  - **박자표(4/4·3/4·6/8)와 템포(♩=164)도 악보에서 읽어** 곡에 자동 반영합니다 — 마디 그리드·메트로놈·카운트인·BPM이 함께 바뀝니다. (트랜스포트에서 직접 바꿀 수도 있습니다.)
  - 리듬을 읽은 경우 창에 "악보의 음표(리듬)를 읽었습니다"가 표시됩니다.
  - **뉘앙스도 함께 읽습니다**: 박 위치 강약(벨로시티), 뮤트 점(·)=짧고 여리게, X=척, 이음줄(타이=한 음으로, 해머링/슬라이드=레가토), 꾸밈음 제외. 가져온 뒤 피아노 롤에서 노트 밝기(=세기)로 확인할 수 있습니다.
  - **스캔·사진(이미지) 악보는 지원하지 않습니다** — 종이를 찍은 PDF는 글자 정보가 없어 읽을 수 없습니다. 악보 프로그램으로 만든 PDF(글자가 복사되는 PDF)만 됩니다.
- **드럼 트랙**: **+ 트랙 추가 → 드럼 트랙**(또는 빈 곳 우클릭)으로 만들면 채널 10 트랙이 생기고 드럼 에디터가 바로 열립니다. 세로축이 드럼 소리(위=크래시 ... 아래=킥)인 피아노 롤식 타임라인 — 클릭/드래그=격자에 스냅해 찍기, Shift=강세, 우클릭=지우기, **Ctrl+드래그=사각 선택**(선택 후 잡아끌면 좌우 이동, Del=삭제, 빈 곳 클릭=해제), **마디 복제**로 반복 비트.
- **내장 드럼 사운드**: 채널 10에서는 내장 신스가 진짜 드럼처럼 합성음을 냅니다 — 킥(펀치+피치 드롭), 스네어(톤+노이즈), 클랩, 햇(짧게/길게), 탐 3종, 크래시/라이드. GM 드럼 VSTi를 얹으면 그쪽 소리로 대체됩니다.
- **드럼 샘플(WAV)**: 드럼 에디터에서 **드럼 이름을 우클릭**하면 샘플 브라우저가 열립니다 — 기본 **"악기별" 탭**은 라이브러리 전체를 킥/스네어/햇 등으로 자동 분류해 보여주고(이름 검색 가능), "폴더" 탭은 원래 구조로 탐색. WAV 클릭 = 배정 + 바로 미리듣기, "신스로 되돌리기"로 해제. 배정은 프로젝트에 저장되고 트랙 볼륨/EQ/FX가 그대로 걸립니다.
- **스윙**: 드럼 에디터 툴바의 스윙 % + [적용] — 엇박(짝수 격자 칸)을 뒤로 밀어 그루브를 만듭니다 (선택이 있으면 선택만). Ctrl+Z로 되돌리기. 피아노 롤에도 [스윙] 버튼이 있습니다.
- **드럼 킷**: 툴바 [킷] — 지금 배정된 샘플 세트를 이름 붙여 저장하고, 어느 프로젝트에서든 클릭 한 번으로 불러옵니다.
- **벨로시티(세기)**: 노트 위에서 **Alt+세로 드래그** — 위=세게, 아래=여리게. 세기는 노트 색 밝기로 보입니다.
- `|◀` = 처음으로 · `◀ 마디` = 현재 마디 시작(연타 시 이전 마디)

## 7. 템포 · 마커 · 루프

- **템포 변경**: 트랜스포트 "템포 변경..." 또는 트랙 뷰 우클릭 → "여기부터 템포 변경". 주황 마커 드래그=이동, 우클릭=BPM/삭제, 클릭+`Del`=삭제. .mid 저장에도 포함.
- **템포 램프 (점점 빠르게/느리게)**: 템포 마커 우클릭 → **"다음 지점까지 점진 변화"** 체크 — 이 지점의 BPM에서 다음 지점의 BPM까지 서서히 변합니다. 램프 마커는 라벨에 `>>`가 붙습니다.
- **구간 마커**: 우클릭 → "여기에 구간 마커 추가". 이름표 클릭=점프, 드래그=이동, 우클릭=이름/삭제, 클릭+`Del`=삭제.
- **구간 복제 (어레인지)**: 마커 이름표 우클릭 → **"구간 복제 (뒤에 삽입)"** — 이 마커부터 다음 마커까지 모든 트랙의 노트/클립/오토메이션/템포를 통째로 뒤에 복사하고, 이후 내용은 그만큼 밀립니다. Verse/Chorus 반복 만들기에 씁니다.
- **어레인지 뷰** (Tool 메뉴): 구간 마커들이 **블록으로** 나열됩니다 — **드래그 = 곡 구조 재배열**(모든 트랙 내용이 통째로 이동), 클릭 = 그 구간으로 점프, 우클릭 = 복제/삭제. 재생 중인 구간은 주황 테두리로 표시됩니다.
- **루프**: 첫 트랙 줄 상단을 드래그해 구간 생성(틱 단위 자유), 파란 띠 가운데 드래그=이동, 끝 핸들=크기. 구간 선택(Ctrl+드래그, 빈 곳도 가능) 후 `L` = 그 구간이 루프. 루프 칸에 반복 횟수 카운터.
- **카운트인**: 켜면 녹음뿐 아니라 **재생 시작 전**에도 정한 횟수만큼 클릭을 셉니다. 루프와 함께 켜면 **매 바퀴 되돌아갈 때마다** 카운트인 후 다시 시작합니다.

## 8. 믹서와 오토메이션

- **믹서**: 마스터(고정) + 전 트랙 스트립. 페이더/미터(피크 홀드·클리핑 램프)/Pan·Gain 노브/뮤트/EQ 노브/FX 체인 박스(▲▼ 순서 변경).
- **마스터 리미터**: 마스터 스트립의 "리미터" 체크(기본 켜짐) — 0dB를 넘는 피크를 눌러 찌그러짐을 막습니다. 지금 누르는 양이 **GR -x.x dB**로 표시되고, [설정]에서 게인/실링/릴리스 조절. 내보내기에도 그대로 적용.
- **센드/리턴 (공용 리버브)**: 각 트랙의 **Send 노브**만큼 신호가 공용 리버브로 갑니다 — 트랙마다 리버브를 거는 것보다 CPU를 아끼고 공간감이 통일됩니다. 마스터 스트립의 **리턴 리버브** 노브로 전체 양, [설정]에서 공간/댐핑.
- **사이드체인 덕킹**: 내장 컴프레서 파라미터 창의 **"사이드체인"** 콤보에서 키 트랙을 고르면, 그 트랙 소리로 이 트랙을 눌러줍니다 — 베이스 컴프레서에 킥 트랙을 걸면 킥마다 베이스가 숙여지는 클래식 덕킹.
- **모니터 이펙트**: ASIO 모니터 소리가 그 트랙의 EQ/FX 체인을 타고 들립니다 (리버브 걸린 소리로 연주). **녹음 파일은 항상 드라이 원본**으로 저장됩니다.
- **곡 미니맵**: 트랙 뷰 상단의 가는 띠 — 곡 전체(클립·노트·루프·재생 헤드)가 축소돼 보이고, 클릭/드래그하면 그 위치로 화면이 이동합니다. 흰 테두리 = 지금 보이는 범위.
- **채널 창**: 마스터 + 선택 트랙만 (왼쪽 상시용).
- **오토메이션**: 트랙 뷰 "오토메이션" 콤보에서 곡선 선택 후 레인에 드래그로 그리기. 우클릭으로 곡선 삭제.
  - **볼륨/팬**: 곡선이 있으면 재생·내보내기에서 페이더 대신 적용 (점 사이 선형 보간).
  - **CC 곡선** (모듈레이션 CC1 / 익스프레션 CC11 / 서스테인 CC64 / 필터 CC74): 실제 CC 이벤트를 심습니다 — 빠르게 드래그해도 사이가 램프로 채워집니다. 보라색 계단 곡선으로 표시되며, VST 악기에 적용됩니다 (내장 신스 제외).

## 9. 버전 분기 (트랜스포트 오른쪽 칸)

- **체크인** → 이름/메모 입력 → **생성**: 현재 곡이 노드로 저장됩니다.
- 노드 클릭 = 그 버전 불러오기. 우클릭 = 이름/메모 수정, 가지 뻗기, 삭제.
- 옛 노드에서 이어서 체크인하면 트리가 갈라집니다. 프로젝트 파일에 함께 저장.

## 10. 내보내기 (`Ctrl+E`)

- 저장 폴더 + 파일 이름, **WAV/MP3(192kbps)** 선택.
- **대상**: 전체 믹스 / 트랙별 스템(트랙마다 파일) / 선택 트랙만.
- **스템 옵션**: Send를 쓰는 트랙이 있으면 **"_리턴리버브" 스템**이 함께 나오고, **[리미터 적용]** 체크 시 각 스템에 마스터 리미터 세팅이 적용됩니다.
- **구간**: 전체 또는 사용자 설정 — 미니 타임라인에서 드래그(마디 스냅)·가장자리 핸들(시간 미세)·마디/초 입력·루프 구간 가져오기.
- 재생 없이 오프라인 렌더라 곡 길이보다 훨씬 빠릅니다.
- **패키지로 내보내기** (파일 메뉴): 프로젝트 + 사용 중인 드럼 샘플을 한 폴더에 모아 저장합니다 — 폴더째 다른 PC로 옮겨도 소리가 그대로 납니다 (오디오 클립/플러그인 상태는 원래부터 프로젝트 옆에 함께 저장됨).

## 12. 문제 해결

- **소리가 끊김**: Tool > 성능에서 오디오 부하 확인 → 버퍼를 키우거나 무거운 트랙을 프리즈.
- **ASIO 장치가 안 보임**: 설정 > 개인설정 > ASIO에서 장치 검색. 드라이버 설치 확인.
- **크래시 후 재실행**: 자동 저장본 복구를 물어봅니다 — 복구 후 원하는 위치에 저장하세요.
- CC 곡선은 내장 신스가 아닌 **VST 악기**에서만 적용됩니다 (해당 CC를 매핑한 플러그인).
